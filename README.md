# 3D Gradients for LightBurn

A tool to generate 3D gradient cutting patterns for use with LightBurn laser software.

## Features

- Create wedge (rectangular), cone (circular), or pyramid (concentric rectangular) 3D gradient patterns
- Customize dimensions, spacing, and cut parameters
- Responsive design works well on both desktop and mobile devices
- Generate LightBurn-compatible files (.lbrn2)

## Usage

1. Select the shape type (Wedge, Cone, or Pyramid)
2. Enter dimensions in millimeters
3. Set cut spacing, speed, and power parameters
4. Click "Generate Lightburn Code"
5. Download the file and open in LightBurn

## About

This tool generates gradient patterns by varying the laser power across multiple lines. When cut into materials like wood or acrylic, these create a 3D effect with varying depths.
