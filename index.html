How to Use This Tool

This tool generates gradient patterns for laser cutting, creating 3D effects when cut at varying power levels.

Basic Steps:

  1. Select Shape Type - Choose between Wedge (rectangular), Cone (circular), or Pyramid (concentric rectangular) patterns
  2. Set Dimensions - Enter the size of your pattern in millimeters
  3. Configure Cutting Parameters - Set spacing, speed, and power levels
  4. Generate Code - Create the LightBurn file for your laser cutter
  5. Download - Save the generated file to use in LightBurn software

Parameter Details:

  • Cut Spacing - Distance between lines (smaller = finer details but longer cutting time)
  • Speed - Laser movement speed (slower = deeper cut)
  • Passes - Number of times the laser will trace each path
  • Min/Max Power - Power range for the gradient effect
